# Adis — MVP

> **Этот репозиторий** содержит серверную часть Adis: AI Backend на FastAPI (`server/`), документацию (`docs/`), Docker и инструменты разработки. Клиентское приложение (PWA, папка `app/`) хранится отдельно; разделы README про него описывают проект целиком.

Персональный ИИ-помощник с долговременной памятью. MVP сделан как **PWA** (Progressive Web App): одно приложение работает в браузере, а на **iPhone и Android** устанавливается на главный экран как обычное приложение — с иконкой, на весь экран и в офлайне.

## Быстрый старт (Windows, ничего устанавливать не нужно)

1. Дважды кликните **`start.bat`**. Откроется браузер с `http://localhost:8080/`.
2. На экране приветствия нажмите **«Демо для презентации»**. Откроется аккаунт с готовыми данными: люди, задачи, события, память.
3. Чтобы открыть с телефона в той же Wi-Fi сети, используйте адрес `http://192.168.x.x:8080/` — его выведет окно сервера. Если Windows спросит о брандмауэре, разрешите доступ.

> По локальному адресу `http://192.168…` браузеры блокируют микрофон, push-уведомления и установку. Для полного показа на телефонах разместите приложение по **HTTPS** (см. ниже).

## Публикация по HTTPS (для показа инвесторам на телефонах)

Папка `app/` — это статический сайт, сборка не нужна. Любой из вариантов:

- **Netlify Drop:** откройте app.netlify.com/drop и перетащите папку `app`. Вы сразу получите HTTPS-ссылку.
- **GitHub Pages:** загрузите содержимое `app/` в репозиторий и включите Pages.
- **Cloudflare Pages / Vercel:** создайте статический проект с корнем `app/`.

Установка на телефон:
- **iPhone (Safari):** «Поделиться» → «На экран Домой».
- **Android (Chrome):** меню ⋮ → «Установить приложение».

## Демо-сценарий для презентации (3 минуты)

1. **Главная** → кнопка-подсказка «Сегодня познакомился с Артёмом…». Adis выделит человека, профессию и навыки и покажет карточку «Сохранить в память». Нажмите «Сохранить».
2. «С кем я недавно познакомился из программистов?» → Adis найдёт Артёма.
3. «Напомни завтра в 10 позвонить Артёму» → карточка напоминания с датой и временем, привязанная к Артёму → «Создать».
4. **Память** → вкладка «Люди» → Артём: навыки, дата знакомства, задача, история взаимодействий.
5. **Голос** (микрофон на главной): полноэкранный режим с волной и озвучкой ответа.
6. **Инструменты** → «Бизнес-аналитика», «Отчёты», «AI-агенты» → запуск агента «Планировщик дня».
7. **Профиль** → «Оформление» → тёмная тема и крупный шрифт (доступность).

## AI Backend (настоящий сервер)

`server/` — FastAPI-сервер, реализующий весь контракт `docs/API.md`: аккаунты, чат со стримингом, память, люди, задачи, календарь, будильники, push-уведомления, документы, проактивные предложения, агенты. Данные каждого пользователя изолированы, ИИ работает только через инструменты с проверкой прав.

Запуск (нужен Python 3.12: `winget install -e --id Python.Python.3.12 --scope user`):

1. Дважды кликните **`start-server.bat`** (или `powershell -ExecutionPolicy Bypass -File server\run.ps1`). При первом запуске создаётся `server\.venv` и ставятся зависимости.
2. Откройте `http://localhost:8000/`. Сервер раздаёт и само приложение, и API (`/v1`, документация — `/v1/docs`).
3. В приложении: **Профиль → Подключение → AI Backend**, адрес `http://localhost:8000/v1`, затем войдите заново.

Настройки — в `server/.env` (образец: `server/.env.example`).

**База данных.** По умолчанию SQLite (`server/data/adis.db`), в продакшене — PostgreSQL 16 (`ADIS_DATABASE_URL`). Схема ведётся миграциями Alembic (`server/migrations`) и обновляется автоматически при старте сервера. Для разработки на этом компьютере есть портативный PostgreSQL без прав администратора: `powershell -ExecutionPolicy Bypass -File tools\pg.ps1 start` (порт 5433, адрес — в `.env.example`).

**Языковая модель.** Подключена OpenAI `gpt-5.4-mini` (ключ — только в `server/.env`, в приложение не попадает). Подходит любой OpenAI-совместимый API (DeepSeek, OpenRouter, Anthropic через совместимый эндпоинт, локальный Ollama): `ADIS_LLM_BASE_URL`, `ADIS_LLM_MODEL`, `ADIS_LLM_API_KEY`. Модель сама ищет в памяти, людях, задачах и календаре и предлагает карточки (память, напоминание, событие, перенос, будильник), которые пользователь подтверждает. Если модель недоступна (сеть, лимит), ответ даёт встроенный движок на правилах с пометкой «упрощённый режим»; без настроенной модели он работает всегда, а в чате у таких ответов стоит метка «без LLM». Живая проверка качества: `server\.venv\Scripts\python.exe server\scripts\llm_eval.py` (стоит доли цента).

**Размещение.** `docker compose up -d --build` поднимает PostgreSQL и Adis (`server/Dockerfile`, контекст сборки — `server/`; чтобы раздавать и PWA, раскомментируйте том `./app` в `docker-compose.yml`). Перед портом 8000 нужен HTTPS (Caddy, nginx или облачный балансировщик): без него телефоны не дают установку, микрофон и push.

### Голос

Микрофон на главной открывает голосовой режим: нажмите и говорите, Adis сам поймёт, когда вы закончили, ответит и озвучит ответ. Микрофон в чате — диктовка.
С сервером голос облачный (OpenAI, тот же ключ): одинаково работает на iPhone, Android и компьютере, правильно пишет имена из памяти, номера телефонов и время — цифрами («Запомни номер Артёма плюс семь девятьсот…» → `+7 999 123-45-67`), озвучка — естественным голосом (выбор в «Профиль → Голос»). Без сервера и в демо — распознавание и озвучка браузера.

### Финансы

**Инструменты → Финансы**: обзор месяца (доходы, расходы, баланс, траты по категориям), долги («Мне должны» / «Я должен»: частичный и полный возврат, история возвратов) и список операций. Записывать можно и словами, текстом или голосом:
«Потратил 1200 на продукты», «Купил кофе за 350», «Получил зарплату 150 тыс», «Дал Артёму 5000 до 25 декабря», «Занял у брата 10к», «Артём вернул 2000», «Я вернул брату долг», «Кто мне должен?», «Сколько я потратил в этом месяце?», «Сколько ушло на кафе?».
Категория определяется сама, суммы распознаются в любом виде (`1 200`, `2,5к`, `150 тыс`, `$50`). Если у долга есть срок, Adis напомнит о нём. Номера банковских карт и CVV по-прежнему не сохраняются.

### Календарь, будильники, уведомления

- **Из чата и голосом:** «Встреча с Марией завтра с 15 до 16 в офисе», «Что у меня в среду?», «Перенеси встречу с Марией на 17:00», «Отмени созвон», «Поставь будильник на 7:30 по будням», «Разбуди меня через 20 минут». Adis показывает карточку; изменения применяются только после подтверждения. При пересечении событий есть предупреждение.
- **Push-уведомления** (Профиль → Уведомления): напоминания, события и будильники приходят, даже когда Adis закрыт. Android — в браузере и в установленном приложении; iPhone — iOS 16.4+, только для приложения, добавленного на экран «Домой». Нужен HTTPS (или localhost).
- **Будильник** (Задачи → значок часов): пока Adis открыт — полноэкранный звонок со звуком, вибрацией и кнопкой «Отложить на 10 минут»; когда закрыт — push-уведомление. Звонить в беззвучном режиме и будить заблокированный телефон, как системные часы, веб-приложение не может — это возможно только в нативной сборке.
- **Синхронизация с телефоном** (Календарь → значок синхронизации): секретная ссылка-подписка iCal для «Календаря» iPhone и Google Календаря, с напоминаниями телефона; импорт файла `.ics`. Подписка работает, когда сервер доступен из интернета по HTTPS.

Тесты сервера: `powershell -ExecutionPolicy Bypass -File server\run.ps1 -Test` (на PostgreSQL — с переменной `ADIS_TEST_DATABASE_URL`).
E2E приложения против сервера (при запущенном сервере): `powershell -ExecutionPolicy Bypass -File tools\page-test.ps1 -Url http://localhost:8000/tests/server.html`. Реальная доставка push через сервис браузера: `... -Url http://localhost:8000/tests/push.html -GrantNotifications`.

## Что пока не готово

- **Push на iPhone/Android по сети** проверен через сервис Microsoft Edge; на телефонах — после размещения по HTTPS. Нативные APNs/FCM понадобятся только для нативной сборки.
- **Письмо для восстановления пароля** отправляется, когда в `server/.env` заполнен SMTP (`ADIS_SMTP_*`, подойдёт Яндекс, Mail.ru, Gmail и т. п.). Без него экран честно сообщает, что почта не настроена.
- **Встроенные агенты** считают аналитику по данным пользователя без LLM и помечены «Демо». **Пользовательские агенты** выполняются языковой моделью: читают память, людей, задачи, календарь и финансы в рамках выданных им прав и только на чтение.
- **Повторяющиеся события** календаря: при импорте `.ics` берётся первое повторение.
- Семантический поиск (pgvector) и вынос лимитов в Redis.

Демо-режим без сервера по-прежнему доступен (`start.bat`): весь API эмулируется в браузере (`app/js/mock/`), данные хранятся только на устройстве с меткой **«Демо»**. Будильники и события из чата работают и в демо; push и подписка календаря — только с сервером.

## Тесты

С запущенным сервером откройте `http://localhost:8080/tests/smoke.html`. Тест проходит 60+ проверок: NLU, сценарий из ТЗ, стриминг, рендер всех экранов, агенты, темы. В конце должно быть `RESULT: ALL PASSED`.

Без окна браузера:
```
"C:\Program Files (x86)\Microsoft\Edge\Application\msedge.exe" --headless=new --virtual-time-budget=150000 --dump-dom http://localhost:8080/tests/smoke.html
```

Тест очищает localStorage для своего origin. После него войдите в демо заново.
